1. Setup & Installation

protobuilder is a pure-Rust project with zero external dependencies. It compiles into a single self-contained native binary that includes the .proto parser, type resolver, embedded standard types, and code generators for all 15 languages.

Step 1: Build the Executable

cd /Users/raenard/Documents/protobuilder
cargo build --release

The standalone binary is produced at:

./target/release/protobuilder

Step 2: Optional Global Installation

Install into ~/.cargo/bin or copy anywhere on your PATH:

# Install via Cargo:
cargo install --path .

# Or copy the single executable directly:
cp ./target/release/protobuilder /usr/local/bin/protobuilder
Ready Out of the Box: No plugins, runtimes, or header packages need to be installed. Everything required to parse and generate Protobuf messages and gRPC services for all 15 languages is built directly into the protobuilder binary.

2. Quick Start Examples

Generate All 15 Languages at Once

Compiles both Protobuf message/enum types and gRPC client/server stubs for all 15 languages:

protobuilder examples/ecommerce.proto -l all -o ./gen

Generate Specific Languages

Pass a comma-separated list (or repeat -l) for the languages your project uses:

protobuilder examples/ecommerce.proto -l rust,go,python,ts -o ./gen

Compile an Entire Directory

Pass a directory path to automatically discover all .proto files and resolve their imports:

protobuilder ./examples -l rust,go,cpp,java -o ./gen

Scaffold & Build a Project

Initialize a starter project with protobuilder.toml and build with zero flags:

protobuilder init ./my-service
cd ./my-service && protobuilder build

Inspect a Schema

View parsed messages, fields, enums, and gRPC service RPC streaming modes:

protobuilder inspect examples/ecommerce.proto

Validate a Schema

Check .proto files for syntax errors, duplicate field tags, or unresolved types:

protobuilder validate ./examples

3. CLI Commands & Options Reference

Commands

Command Description Example
build Compile .proto files or directories into target language files (default command when omitted). protobuilder build api.proto -l rust,go -o ./gen
init [DIR] Scaffold a starter project with a sample protos/service.proto and protobuilder.toml. protobuilder init ./my-grpc-app
inspect <PROTOS>... Display parsed packages, imports, options, enums, messages, fields, and gRPC services. protobuilder inspect examples/ecommerce.proto
validate <PROTOS>... Validate syntax, field numbers, reserved ranges, imports, and gRPC message types. protobuilder validate ./examples
languages List all 15 built-in languages, their short aliases, and generated file patterns. protobuilder languages
help [TOPIC] Display the CLI help guide or topic-specific help (languages, config). protobuilder --help

Options

Option Description
-l, --lang <LANGS> Target language(s) to generate. Accepts all (default), a comma-separated list like -l rust,go,python,ts, or repeated -l flags.
-o, --out <DIR> Output directory (default: ./gen). Writes directly to <DIR> when generating a single language, or into <DIR>/<lang>/ subfolders when generating multiple languages.
-I, --include <DIR> Add a directory to the import search path. Parent directories of input files and standard google/protobuf/*.proto types are resolved automatically.
-c, --config <FILE> Load project configuration from a TOML file (auto-loads ./protobuilder.toml when present).
--grpc-only Generate only gRPC client & server service stubs (skip message and enum definitions).
--messages-only Generate only Protobuf message & enum definitions (skip gRPC service stubs).
--clean Clean the output directory before writing newly generated files.
--dry-run Validate and run code generation in memory without writing files to disk.
-v, --verbose Print every generated file path and byte count.
-q, --quiet Suppress non-error output.
-h, --help Show detailed help and usage examples.
-V, --version Show version information.

5. Project Configuration (protobuilder.toml) & Built-In Standard Types

Sample protobuilder.toml

When present in the working directory, running protobuilder or protobuilder build automatically reads this file:

# protobuilder.toml
inputs    = ["examples/ecommerce.proto"]
includes  = ["examples"]
languages = ["all"]
out_dir   = "./gen"
grpc      = true
messages  = true

Built-In Standard Protobuf Imports

The following standard google/protobuf/*.proto imports are embedded inside the binary and automatically resolved:

  • google/protobuf/timestamp.proto (Timestamp)
  • google/protobuf/duration.proto (Duration)
  • google/protobuf/empty.proto (Empty)
  • google/protobuf/wrappers.proto (StringValue, Int64Value, etc.)
  • google/protobuf/any.proto (Any)
  • google/protobuf/field_mask.proto (FieldMask)
  • google/protobuf/struct.proto (Struct, Value, ListValue)
  • google/protobuf/descriptor.proto (FileDescriptorSet)
